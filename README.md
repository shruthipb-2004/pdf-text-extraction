# PDF Text Extraction System

## 📌 Overview

The PDF Text Extraction System is a Python-based project developed to automatically extract text from PDF documents. The application reads the PDF page by page, extracts available text, and displays the output. It is useful for converting information from PDF documents into editable and processable text.

## 🚀 Features

* Reads PDF files using Python.
* Extracts text from multiple pages.
* Processes pages automatically using loops.
* Displays extracted content in a readable format.
* Checks whether a PDF contains extractable text.
* Handles basic file and PDF errors.

## 🛠️ Technologies Used

**Python | PyPDF2 / pypdf | Jupyter Notebook**

## ⚙️ Workflow

```text
Select PDF
    ↓
Open PDF
    ↓
Read Pages
    ↓
Extract Text
    ↓
Check Content
    ↓
Display Output
```

## 📚 Learning Outcomes

This project helped me understand Python file handling, external libraries, loops, conditional statements, exception handling, and basic PDF processing. I also learned the difference between text-based and scanned PDFs.

## ⚠️ Challenges

The main challenges included handling PDFs with different layouts, pages without extractable text, incorrect file paths, and invalid PDF files.
